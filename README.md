# Pillar Two Owner Dashboard

A small, self-contained executive dashboard concept for Pillar Two project tracking. The public demo uses synthetic example data only. It does not contain client records or connect to a live workbook.

## Open

Open `index.html` in any modern browser. No server, dependencies, or build step are required.

## Demo interactions

- Filter by fiscal year, jurisdiction, and scope status
- Search client, obligation, or owner (synthetic demo values)
- Browse tasks and open a task detail dialog
- Review the five executive indicators and the cash-impact placeholder

## Data note

All names and task values in the public demo are fictional. Tax amount and cash impact are intentionally shown as unavailable because they require reviewed source inputs.
